# Loman Studio — Color Studio

**Loman Studio** is a modern, responsive color toolkit designed to help designers and developers explore colors, create harmonious palettes, build beautiful gradients, and check color accessibility.

Built with **HTML5, CSS3, and vanilla JavaScript**, it provides a clean interface and practical tools for everyday design and frontend development workflows.

### Features

- 🎨 Interactive color picker with HEX, RGB, and HSL editing
- 🌈 Color palette generation with multiple harmony modes
- 🎯 Interactive color wheel
- 🖌️ Customizable CSS gradient generator
- ♿ WCAG contrast ratio checker
- 👁️ Approximate color vision deficiency simulations
- ⭐ Save and manage favorite colors
- 📦 Export palettes to CSS, SCSS, SVG, JSON, GPL, and ASE formats
- 📱 Responsive design for desktop, tablet, and mobile
- 🧪 Automated tests for color utility functions

### Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Browser Local Storage
- Node.js built-in test runner

### Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/loman-color-studio.git
```

Open the project folder and launch `index.html` in your browser. No package installation or build process is required.

### Purpose

Loman Studio aims to make color exploration, palette creation, and accessibility checking easier through a lightweight, browser-based design toolkit.

**Made for designers and developers who think in color.**
